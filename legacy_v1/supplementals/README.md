# Supporting Information

Figures and tables accompanying "PeptiLine: an interactive platform for
customizable functional peptidomic visualization and analysis" (Kuhfeld,
Nielsen, Dallas; *Journal of Proteome Research*, under review). These are the
same files the hosted app serves at
[`/peptiline/supplementals/`](https://mbpdb.nws.oregonstate.edu/peptiline/supplementals/).

Interactive figures (S1-S5) are standalone Plotly HTML; open them in a
browser. S6 is a static image (PNG and TIFF).

Figure and table captions in full are in the manuscript's Supporting
Information document. S6-S9 Fig (Welch's t-test comparisons for count,
abundance, function, and casein subsets) are generated dynamically by the
hosted app rather than shipped as static files here.

`legacy_v1/` holds supplemental files from an earlier manuscript draft
(different S-numbering, a wound-healing case study since replaced by the
hibernation case study) kept for reference; they do not match the current
Supporting Information document.
